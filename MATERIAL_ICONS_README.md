## 📋 How to Use the Application

### Manual Search
1. Type a location in the search box (e.g., "Venice, Italy")
2. Optionally adjust radius and dates
3. Click "Discover Available Scenes"
4. View results on the map and in the table below

### Voice Search
1. Click the microphone icon
2. Say: "Search Scenes for Location: Venice Italy, Radius: 15 km, TimeInterval 2025-01-15 till 2025-02-15"
3. The form fields auto-fill
4. Search executes automatically

### Reset
1. Click the refresh icon to clear all fields
2. Ready for a new search

## 📊 Technical Specifications

### Material Icons Library
- **Source**: Google Fonts (CDN)
- **License**: Apache 2.0 (Open Source)
- **Load Time**: <100ms
- **Size**: Minimal (external CDN)
- **Icons**: 1000+ available

### Implementation
- **HTML**: `<span class="material-icons">icon_name</span>`
- **CSS**: Font-size: 24px for button icons, 20px for search button
- **Compatibility**: All modern browsers
- **Performance**: No impact on page load

## 🎓 For Future Development

### Want to add more Material Icons?
1. Open [Material Icons Library](https://fonts.google.com/icons)
2. Find desired icon name
3. Replace in code: `<span class="material-icons">icon_name</span>`
4. All 1000+ icons are available

### Available Icons Examples
- `location_on` - Map location
- `calendar_today` - Calendar
- `settings` - Settings
- `home` - Home
- `info` - Information
- `help` - Help
- `error` - Error
- And 1000+ more!
